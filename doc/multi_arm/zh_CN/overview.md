# 使用前准备

## 环境与文件

正确安装艾利特机器人的 ROS 2 驱动（如果还未安装，可以参考快速手册的相关章节进行安装）。

在已加载 ROS 2 与目标工作空间环境的终端中，检查已安装的软件包版本：

```bash
ros2 pkg xml -t version elite_robots

ros2 pkg xml -t version elite_robots_description
```

## 场景区别

- 实体机器人：两台控制器地址均应可达，并能回连 ROS 计算机；无头模式下按机器人配置启用远程控制。
- ELIBOTSim：使用两个独立模拟控制器的可达地址，并满足相同的回连及端口条件；不要把两台机械臂都指向同一个控制器实例。
- fake hardware：不连接机器人，用于关节与命名空间集成；它不是完整控制柜模拟器。
