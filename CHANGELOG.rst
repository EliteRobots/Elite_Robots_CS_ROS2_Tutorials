Changelog for package elite_robots_cs_tutorials
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

1.0.0 (2026-11-03)
------------------
* Provide independent Chinese and English quickstart, interface, multi-arm,
  and Tutorials manuals, with separate HTML sites and PDF output.
* Use the stock Read the Docs HTML theme and remove the unused custom theme.
* Export referenced downloads alongside each PDF, preserving readable file
  names and example package directories, including PDF-only builds.
* Package complete MoveIt examples as reproducible ZIP downloads.
* Support Windows PDF builds using latexmk and XeLaTeX, and retain the
  document/language output layout under build/docs.
* Clarify apt, source workspace, and Bash environment setup in both quickstart
  editions; update their revision date to 2026-11-03.
* Set the ROS documentation package version to 1.0.0. Keep manual versions
  independent; all eight enabled document/language combinations are 1.0.0
  in this package baseline.
* Add this package-level changelog and install it with the package metadata.
