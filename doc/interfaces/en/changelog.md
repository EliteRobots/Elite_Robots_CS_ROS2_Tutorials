# Revision history

## 1.0.0 · 2026-09-28

- First independent English ROS 2 interface reference, translated from Chinese version 1.0.0 dated 2026-09-24. Covers nine ROS packages in the Description, Driver, and GZ Simulation repositories.
- Documents model interfaces, launch arguments, hardware resources, controller topics/services/actions, Dashboard, Primary, scripts, MoveIt, Servo, and calibration tools.
- Includes complete fields and constants for 6 custom messages and 11 custom services.
- Explains five-axis/six-axis differences, interface availability, speed units, asynchronous result limitations, and separate launch steps for Gazebo 1.0.1.
- Retains the Humble source review baseline; no operational validation with physical robots, ELIBOTSim, or Gazebo has been performed. The corresponding Jazzy versions have not been reviewed.
