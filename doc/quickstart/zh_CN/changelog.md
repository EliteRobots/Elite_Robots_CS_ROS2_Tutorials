# 修订记录

本章记录正式手册中影响使用的变化。文档版本独立维护，适配的软件包版本见[适用版本](index.md#适用版本)；详细源码核对依据保存在仓库维护资料中。

## 1.0.0（2026-09-24）

- 建立独立版本的 MyST 快速使用手册，生成对应的 HTML 与 PDF，并采用按文档类型和语言组织的目录结构。
- 根据当前工作空间源码修订安装、驱动启动、服务调用、控制器及 Python/C++ 运动示例，修正参数格式和 `max_vel` 的单位说明。
- 更新 MoveIt 2 启动命令，补充 Gazebo 分步启动、控制器选择及仿真时钟检查方法。
- 整理正文图片的编号、文件名与引用。
- 补充适用版本表：Driver 仓库内各 ROS 包为 1.2.0，Description 为 1.0.0，SDK 为 1.4.7；Gazebo 按待修复目标版本 1.0.2 记录。

- 统一 HTML 品牌样式，增加左右目录、搜索、代码复制和移动端导航。

本版完成了文档构建与源码核对；实机运动及 Gazebo 运行验证尚未完成。Gazebo 1.0.2 的修复尚未完成，不代表该版本已发布或通过验证。
