# 修订记录

本章记录多机械臂手册的内容变化，文档版本独立于 ROS 包版本。

## 1.0.0（2026-11-03）

- 提供独立的中英文多机械臂手册，覆盖 launch 文件组织、双臂驱动、启动流程、控制器与轨迹控制，以及 MoveIt 2 配置。
- 提供 `dual_arm_control.launch.py` 和 `dual_moveit.launch.py` 完整模板，支持按文件名直接启动，并提供对应下载。
- 说明各机械臂的 namespace、TF/joint prefix、controller manager、通信端口及控制器的隔离配置。
- 补充逐臂查询控制器和轨迹 action 的操作，以及虚拟硬件与真机的启动方式。
- 补齐首页版本号、修订日期和本修订记录，与文档清单中的 `1.0.0` 保持一致。

本记录汇总当前文档基线；文档构建检查不代表完成实体机器人或仿真运行验证。
