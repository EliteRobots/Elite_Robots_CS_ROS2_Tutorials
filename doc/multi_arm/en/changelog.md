# Revision history

This chapter records changes to the multi-arm guide. Its document version is independent of the ROS package version.

## 1.0.0 (2026-11-03)

- Provide independent Chinese and English multi-arm guides covering launch file organization, dual-arm drivers, startup, controllers and trajectory control, and MoveIt 2 configuration.
- Provide complete `dual_arm_control.launch.py` and `dual_moveit.launch.py` templates that can be launched directly by filename, with corresponding downloads.
- Explain separate namespaces, TF/joint prefixes, controller managers, communication ports, and controllers for each arm.
- Include per-arm controller and trajectory action queries, plus startup procedures for fake hardware and physical robots.
- Add the version declaration, revision date, and this revision history, matching version `1.0.0` in the document manifest.

This entry summarizes the current document baseline. Documentation build checks do not constitute validation on physical robots or in simulation.
