# Elite Robots ROS 2 Tutorials

**Elite Robots**

Document version: **1.0.0** · Revised: **2026-10-08**

Build a custom CS63 workcell, connect the driver, configure MoveIt 2, and write a C++ planning application. Each step explains the purpose of the configuration, the relationships between files, and how to check the result.

The examples target ROS 2 Humble with `elite_robots_driver` 1.2.0, `elite_robots_moveit_config` 1.2.0, and `elite_robots_description` 1.0.0. They use a six-axis CS63, the `cs63_` prefix, and the `elite_arm` planning group.

Download the complete examples:

- {download}`hello_moveit.zip <../downloads/hello_moveit.zip>`
- {download}`my_elite_robot_cell.zip <../downloads/my_elite_robot_cell.zip>`
