# Elite Robots ROS 2 Tutorials

**艾利特智能机器人股份有限公司**

文档版本：**1.0.0** · 修订日期：**2026-10-08**

本教程通过 CS63 自定义工作单元，讲解如何组合机器人模型、接入驱动、配置 MoveIt 2，并编写 C++ 规划程序。每一步同时说明配置的作用、文件之间的关系和检查方法。

适用环境为 ROS 2 Humble，配套 `elite_robots_driver` 1.2.0、`elite_robots_moveit_config` 1.2.0 和 `elite_robots_description` 1.0.0。示例使用六轴 CS63、`cs63_` 前缀和 `elite_arm` 规划组。
